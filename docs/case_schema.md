# Case Schema 说明

`EngineeringCase` 用来保存可复用的工程知识：

- `case_id`
- `module`
- `task`
- `old_algorithm`
- `new_algorithm`
- `constraints`
- `steps`
- `problems`
- `solutions`
- `validation`
- `final_status`
- `reusable_experience`
- `source_conversation_id`

这个 Schema 保存的是经过整理和验证的结论，而不是原始聊天里的重复信息、试错过程和临时错误判断。
